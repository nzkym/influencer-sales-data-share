# 쿠팡 로켓배송 + 올리브영 매출 데이터 집계 프로그램

## 프로그램 개요
쿠팡 로켓 입고상세내역, 올리브영 매출(원본 시트)을 매일 자동으로 읽어,
월별/SKU(품명)별 입고·매출 데이터를 집계해서 결과 시트에 덮어쓴다.
담당직원(조은혜) 인센티브 계산용 자료로 사용한다.

---

## 데이터 흐름

```
[쿠팡] 원본 시트 (쿠팡 로켓 입고상세내역, 2025.01~)
  └─ 행 단위: 수집일시 / 구분 / SKU명 / 입고·반출일자 / 수량 / 총 단가 ...
       ↓ 구분 == "발주" 인 행만, (년월, SKU명)별로 집계

[올리브영] 원본 시트 (*26년 매출)
  └─ 행 단위(구분=="전체"): 브랜드명 / 상품코드 / 품명 / [월별 블록: 합계수량·합계매출·일평균·일별...]
       ↓ 월별 블록의 "합계 매출" 컬럼을, (년월, 품명)별로 집계

[업체 총 매출] 원본 시트 (매출)
  └─ "합계" 행(현재 연도 + 직전 연도, 1~12월 컬럼)에서 년월별 총매출 추출

결과 시트 (1ab_Pha20ULYGh__gzzV59BRIoR4x_HSCEY9TiAMYWPw)
  ├─ '쿠팡 로켓 입고내역' 탭: 년월 / SKU명 / 입고수량 / 입고금액(총단가,단위:원)  (년월 최신순)
  ├─ '올리브영 매출' 탭:     년월 / 품명 / 매출액  (년월 최신순)
  └─ '인센티브 계산' 탭:     년월 / 인센티브 총합
                              / 쿠팡 로켓 입고금액(총단가,단위:원) / 직전3개월평균대비 증감금액 / 직전 3개월평균 / 쿠팡 인센티브
                              / 올리브영 매출 / 올리브영인센티브 & 내용
                              / 업체 총 매출 / 직전3개월평균대비증감
```

매 실행마다 각 탭을 전체 재계산해서 덮어쓰므로, 원본 시트에 새 행/데이터가
추가되기만 하면 별도 작업 없이 다음 실행에 반영된다.
각 탭 1행에 "마지막 업데이트: YYYY-MM-DD HH:MM" (한국시간)을 기록한다.

### '인센티브 계산' 탭 — 컬럼 구성 (A~J)

| 열 | 헤더 | 내용 |
|---|---|---|
| A | 년월 | YYYY-MM |
| B | 인센티브 총합 | F(쿠팡 인센티브) + H의 인센티브 금액 |
| C | 쿠팡 로켓 입고금액(총단가,단위:원) | 해당월 쿠팡 로켓 입고금액 합계 |
| D | 직전3개월평균대비 증감금액 | C - E |
| E | 직전 3개월평균 | 해당월 기준 직전 3개월 C값의 평균 |
| F | 쿠팡 인센티브 | D가 500만원 이상이면 D × 1%, 그 외(0 또는 음수)는 0 |
| G | 올리브영 매출 | 해당월 올리브영 전체 품목 매출액 합계 |
| H | 올리브영인센티브 & 내용 | 월매출 구간별 인센티브율 적용 + 최초 구간돌파 1회성 보너스 |
| I | 업체 총 매출 | '매출' 시트(원본)의 "합계" 행에서 해당 년월의 총매출 |
| J | 직전3개월평균대비증감 | I - (직전 3개월 I값의 평균) |

### B,D~F열 — 쿠팡 인센티브 관련

- E(직전 3개월평균) = 해당월 기준 직전 3개월 입고금액(C열)의 평균
- D(증감금액) = 해당월 입고금액(C) - E
- F(쿠팡 인센티브) = D가 500만원 이상이면 D × 1%, 그 외(0 또는 음수)는 0
- 당월(가장 최근 달, 아직 데이터 취합 중)은 B,D~F,H를 비워두고, 다음달 실행부터 계산됨
- `INCENTIVE_START_MONTH`(현재 "2026-06") 이전 달의 B,D,E,F,H 값은 기존 입력값을 그대로 보존하고 재계산하지 않음

### G~H열 — 올리브영 인센티브

- G(올리브영 매출) = 해당월 올리브영 전체 품목 매출액 합계
- H(올리브영인센티브 & 내용) = 월매출 구간별 인센티브율 적용 + 최초 구간돌파 1회성 보너스
  - 구간별 인센티브율 (월매출 기준): 0~500만 0.5% / 500~1000만 1% / 1000~2000만 1.2% / 2000~3000만 1.5% / 3000만 이상 2.0%
  - 최초 구간돌파 보너스(1회성, 월매출 기준 최초 달성 시 1번만 지급): 300만→5만 / 500만→10만 / 1000만→20만 / 2000만→30만 / 3000만→50만
- 당월(가장 최근 달)은 G만 표시(매출 진행상황)하고 H는 비워두며, 다음달 실행부터 계산됨
- 보너스의 "최초 달성 여부"는 매 실행 시 년월 오름차순으로 처음부터 다시 판정하므로 별도 상태 저장이 필요 없음

### I~J열 — 업체 총 매출

- I(업체 총 매출) = '매출' 시트(원본, 판매처별 월매출)의 "합계" 행에서 해당 년월의 1~12월 컬럼값
  - 항상 재계산 (실제 매출 데이터이므로 INCENTIVE_START_MONTH 영향 없음)
- J(직전3개월평균대비증감) = I - (해당월 기준 직전 3개월 I값의 평균)
- 당월(가장 최근 달)은 J를 비워두고, 다음달 실행부터 계산됨 (INCENTIVE_START_MONTH 무관, 매번 재계산)

## 주의사항

- `.env` 파일은 절대 Git에 올리지 않는다
- 오류 발생 시 텔레그램으로 알림 전송 (`TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` 미설정 시 생략)
- 원본 시트에서 "구분"이 "발주"가 아닌 행(반출/취소 등)이 생기면
  `aggregate()` 함수의 필터 로직을 함께 검토해야 한다
- '인센티브 계산' 탭의 헤더(B,E열명)와 F~H열은 코드에서 매번 재작성되므로,
  탭/헤더명을 수동으로 또 바꾸는 경우 `INCENTIVE_HEADERS`도 함께 수정해야 함
