# 파마브로스 정산 계산 규칙

> ⚠️ **절대 원칙: 파마브로스 정산은 반드시 옵션별 설정 단가(공구 판매가)로 계산한다.**
> 실결제금액(쿠폰 적용 후 금액)으로 계산하면 안 된다. 이유 불문.

## 핵심 원칙: 설정된 옵션별 단가(공구 판매가) 기준

파마브로스 정산은 **네이버에서 설정한 공구 판매가(정가)** 기준으로 계산한다.
쿠폰 할인, 네이버페이 포인트 등 실결제금액과 무관하다.

---

## 단가 계산 공식

```
공구 판매가(단가) = (initialProductAmount - initialProductImmediateDiscountAmount) ÷ 수량
```

- `initialProductAmount`: 즉시할인 전 정상가 × 수량
- `initialProductImmediateDiscountAmount`: 공구가 설정에 의한 즉시할인 금액
- `totalPaymentAmount` (실결제금액) **사용 금지** — 쿠폰 등 추가할인이 반영되어 정가보다 낮을 수 있음

**같은 옵션이면 어떤 주문에서 계산해도 항상 동일한 단가가 나온다.**

---

## 포함/제외 기준

| 주문상태 | 처리 |
|---------|------|
| 정상 주문 | ✅ 포함 |
| 반품(RETURNED) | ✅ 포함 (파마브로스 측 합산 기준과 동일) |
| 취소(CANCELED) | ❌ 제외 |

---

## 단가 우선순위

1. **API 기반 정가 (pharmabros_prices/{상품번호}.json)** — 항상 우선
2. xlsx 파일의 단가 컬럼 — API 정가 없을 때만 참조
   - 엑셀 수식 문자열(`=SUM(...)` 등)은 자동으로 무시

---

## 처리 흐름

```
네이버 주문 API
  └─ (initialProductAmount - initialProductImmediateDiscountAmount) ÷ 수량
  └─ 옵션별 단가 → pharmabros_prices/{상품번호}.json 저장

Drive xlsx (파마브로스가 업로드한 파일)
  └─ 각 주문행의 옵션명으로 pharmabros_prices에서 단가 조회
  └─ 단가 × 수량 합산 → 정산 합계

정산서 PDF
  └─ 합계 × 수수료율(마스터시트 J열) = 정산기준금액
  └─ Drive '정산서' 폴더에 자동 업로드
```

---

## 두 가지 결과물

캠페인 종료 후 자동 생성되는 결과물:

1. **Drive 업로드건 xlsx** (`{인플루언서명}_{날짜}_최종_업로드건.xlsx`)
   - 공구 기간 내 전체 주문 내역
   - 파마브로스 Drive 폴더에 업로드

2. **정산서 PDF** (`{인플루언서명}_{날짜}_최종_정산서.pdf`)
   - 합계금액, 수수료율, 정산기준금액 포함
   - Drive '정산서' 폴더에 자동 업로드

---

## 주의사항

- pharmabros_prices 캐시가 잘못된 경우(totalPaymentAmount 방식으로 생성된 경우):
  서버에서 `rm pharmabros_prices/*.json` 후 재실행하면 올바른 정가로 재생성됨
- 캠페인 단가 확인: 파마브로스에서 공유한 최종 합산 금액과 일치 여부로 검증
